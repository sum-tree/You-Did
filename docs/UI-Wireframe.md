# You Did! — Mobile UI v0.3（当前界面参考）

本文描述按[PRD v0.3第5节](PRD.md)实现的v0.3界面，用于核对现状；需求以PRD为准。

## 设计原则

暖白底、自然绿色、浅桃色奖励提示，辅以不同任务类型的柔和色彩。页面优先呈现可操作的信息，不放装饰性口号、大空状态插画或重复统计。

画布参考390 × 844px，最大宽390px；桌面显示居中手机画布。宽320px时收窄边距，内容保持纵向滚动、无水平溢出。底部固定成就、每日、待办、日历四页入口并预留安全区，默认进入每日。顶部为品牌、卡拉米余额、设置；待办和日历页在最右侧额外显示主操作「+」。完成圆圈、「+」、日期格均有可访问名称；进度条提供数值。尊重系统减少动画偏好。

## 成就

本周起止日期 → 一行「我的卡拉米 + 余额」 → 「待办项」：香港揾工、大胆说口语（名称、百分比、进度条） → 课程作业（第N/15周、进度条、调整周数） → 折叠的卡拉米明细。

子目标计数和挑战说明不在本页显示，规则解释放在设置；目标与挑战奖励仍自动结算。

## 每日

本地日期 / 自动或手动安排入口 → 今日完成数与获得卡拉米 → 到期/逾期提醒（如有，超过3项时默认展开，可直接改DDL） → 今日任务列表。

自动安排时按[PRD 6.5](PRD.md)放入每周自动任务（简历一条、口语一条）。列表先列未完成核心任务（最多3项），再列当天完成的任务（已勾选、不可再次完成），按任务ID去重。没有任务时只显示「今天暂无任务」。本页没有新增任务入口。手动安排弹窗最多勾选3项，可保存空选择，也可恢复自动安排。

## 待办

结构化清单：清单内工具栏（计划周筛选：本周/下周/往周/已清空；类型筛选；显示已完成） → 表头（完成、标题、类型、DDL、优先级） → 任务行 → 清单底部未完成数量与批量「移至下周」「清空」。

点标题展开计划周、目标贡献与数量、DDL说明和「任务操作」；任务操作可编辑/改DDL、加入或移出今日、移至下周、清空或恢复。空清单保留表头并显示「暂无记录」。批量操作确认时显示受影响数量，只处理当前筛选的未完成任务。

添加/编辑底部表单：标题（下方一行显示识别出的目标贡献与数量） → 类型 → 优先级（P0/P1/P2）和可选DDL（默认留空） → 新建时可选加入今日 → 保存。目标贡献与数量由标题关键词和数字识别；新任务计划周固定为本周，编辑时保留原计划周，跨周用「移至下周」。

## 日历

月份标题 / 前后月按钮 → 周一至周日网格（今天、选中日期、非本月日期样式不同，有事项的日期显示圆点） → 回到今天。

点日期打开底部面板，列出当天事项的时间、类型、标题、备注，并可编辑或移除；无事项时显示简短提示。右上角「+」添加提醒，默认使用选中日期。普通任务不会出现在日历。

## 设置

手动学期周数 → JSON导出与导入 → 奖励规则与进度计算说明 → 版本号。备份导入验证失败时保持原记录；确认替换前提醒导出旧记录。数据保存失败以可见提示呈现。
