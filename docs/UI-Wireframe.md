# You Did! — Mobile UI v0.2

## 设计原则

暖白底、自然绿色、浅桃色奖励提示，辅以不同任务类型的柔和色彩。信息围绕「今天先完成几件事」组织，轻度游戏化，不用失败惩罚。植物插画寓意缓慢成长，以CSS绘制，不依赖外部图片。

画布参考390 × 844px，最大宽390px；桌面显示居中手机画布。宽320px时收窄边距，内容保持纵向滚动。底部固定每日、成就、待办、日历四页入口并预留安全区。主要操作有文本标签，完成圆圈提供任务名称的可访问标签；进度条提供数值。尊重系统减少动画偏好。

## 每日

顶部品牌 / 卡拉米余额 / 设置 → 本地日期和正向鼓励 → 今日完成及奖励汇总 → 到期/逾期提醒（如有） → 今日专注0至3项 / 手动安排 → 添加一小步 → 今日完成记录 → 本周积累入口。

核心卡片显示完成按钮、任务名称、类型、DDL、优先级、目标贡献、+5奖励和操作菜单。点完成即时发奖；操作菜单可修改DDL、从今日移出、加入今日、移至下周或清空。任务池为空时提供清晰的首次添加入口。

手动安排弹窗最多勾选3项，可保存空选择，也可恢复自动安排。超限时给出提示，不能静默隐藏用户新增任务。

## 成就

余额与本周汇总 → 香港揾工卡片（两个子目标与合并进度） → 口语卡片（两个子目标与听力挑战） → 课程卡片（第N/15周，调整入口） → 卡拉米明细。

基础目标未达标时挑战呈锁定说明；达标后自动展示已获奖励档数。已发基础奖励不因新增面试收回；当前进度与已领奖状态分别展示。

## 待办

待完成汇总 / 新任务 → 本周、下周、往周、已清空分段 → 三类筛选 → 清单 / 显示已完成 → 当前筛选的批量跨周与清空入口。

添加/编辑底部表单：标题 → 类型 → 目标贡献 → 数量 → 优先级和DDL → 计划周 → 可选加入今日 → 保存。切换类型会更新适用贡献类型，避免口语贡献被误记为简历投递。清空记录可恢复，批量操作先显示数量及影响。

## 日历

月份标题 / 前后月按钮 → 周一至周日网格 → 当前选择日期事项 → 新增事件。重要事件以圆点标记；普通任务不会作为日历事件出现。

事件卡片展示事项类型、时间、标题和备注；详情提供编辑及移除。添加表单包含标题、日期、时间、类型和备注。界面说明提醒只在应用内提供。

## 设置

手动学期周数 → JSON导出与导入 → 奖励规则说明 → 版本号。备份导入验证失败时保持原记录；确认替换前提醒导出旧记录。数据保存失败以可见提示呈现。
