# You Did! — Mobile UI v0.6（当前界面参考）

本文描述按[PRD v0.6第2、3节](PRD.md)实现的界面，用于核对现状；需求以PRD为准。

## 设计原则

暖白底、自然绿色、浅桃色奖励提示，辅以不同任务类型的柔和色彩。页面优先呈现可操作的信息，不放装饰性口号、大空状态插画、倒计时或重复统计；逾期不做惩罚式呈现。

画布参考390 × 844px，最大宽390px；桌面显示居中手机画布。宽320px时收窄边距，内容保持纵向滚动、无水平溢出。完成圆圈、「+」、日期格均有可访问名称；进度条提供数值；卡拉米罐有文字替代。尊重系统减少动画偏好。

## 全局框架

顶部：品牌（点击回到每日） / 卡拉米余额（点击切到卡拉米板块） / 页面专属操作（成就：设置与备份；每日：添加任务「+」；待办：添加待办「+」；日历：添加提醒「+」；卡拉米板块无）。

顶部下方为「任务 / 卡拉米」分段切换。任务板块底部导航为成就、每日、日历，默认进入每日；卡拉米板块不显示底部导航。

## 成就

本周起止日期 → 「我的卡拉米 + 余额」（点击展开/收起明细，默认收起） → 「待办项」：香港揾工、大胆说口语（名称、百分比及下方「已完成」小字、进度条） → 课程作业（第N/15周及「已完成」小字、进度条）。

## 每日

本地日期 / 自动或手动安排入口 / 「待办 ›」按钮 → 今日完成数与获得卡拉米 → 今日任务列表。卡片显示标题、类型、优先级，有DDL的未完成任务另显示截止情况；未完成的面试另显示「完成可得X · N天后变为Y」。

列表先列未完成核心任务（最多3项），再列当天完成的任务（已勾选），按任务ID去重。没有任务时只显示「今天暂无任务」。右上角「+」添加任务，今日未满3项时默认勾选加入今日。手动安排弹窗最多勾选3项，可保存空选择，也可恢复自动安排。

## 待办（从每日进入）

「‹ 每日」返回 / 标题「待办」 → 清单内工具栏（计划周筛选：本周/下周/往周/已清空；类型筛选） → 「未完成 N 项」 → 表头（标题、优先级、类型、DDL） → 任务行。底部导航保持高亮每日。待办只显示未完成任务、没有完成圈；每周自动任务每个系列合并成一行（香港秋招简历投递、英语口语练习、粤语口语练习），不显示次数、不可展开；已清空视图逐条显示。

点标题展开计划周、目标贡献与数量、DDL说明、面试奖励提示和「任务操作」；任务操作可编辑/改DDL、加入或移出今日、移至下周、清空或恢复；当天完成的任务在每日卡片菜单里可「撤销完成」。空清单保留表头并显示「暂无记录」。不提供批量操作。

添加/编辑底部表单：标题 → 类型 → 优先级（P0/P1/P2）和可选DDL（默认留空） → 新建时可选加入今日 → 保存。目标贡献与数量由标题关键词和数字识别。

## 日历

月份标题 / 前后月按钮 → 周一至周日网格（今天、选中日期、非本月日期样式不同，有事项的日期显示圆点） → 回到今天。点日期打开底部面板查看、编辑或移除事项；右上角「+」添加提醒，默认使用选中日期。

## 卡拉米

余额大数字「N 颗卡拉米」 → 玻璃罐（软木色盖子、透明罐身与高光；罐内为红、绿、蓝半透明果冻团子（轮廓全为圆弧，底角圆润），带高光、两点眼睛和小尖嘴，自下而上交错堆叠，每罐100颗） → 已装满的罐用小罐图标「已装满 N 罐」 → 「获得记录」列表（倒序）。上次查看后新得的卡拉米在打开时从罐口落下回弹。

## 设置

手动学期周数 → JSON导出与导入 → 奖励规则与进度计算说明 → 版本号。备份导入验证失败时保持原记录；确认替换前提醒导出旧记录。数据保存失败以可见提示呈现。
