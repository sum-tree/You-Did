# You Did! — PRD v0.4

更新日期：2026-10-12。本文描述 You Did! 当前的产品定义与已上线功能，是后续需求的基线。实现与验收进度见[开发交接记录](STATUS.md)，界面细节见[移动端设计](UI-Wireframe.md)。

需求来源：原[分享对话](https://chatgpt.com/share/6acc82b7-deac-83e8-b8ad-a9b3c612a8e5)、[You Did交接文档](https://docs.google.com/document/d/10GCk_kuH4yqQ25rqpvss-DYORzc_5t8N9XtaZcp7pAw/edit?usp=sharing)及后续由用户确认的规则。

## 1. 应用核心

**You Did! 是一款用即时奖励推动用户完成每天求职与学习任务的个人效率应用。**

- **服务对象**：同时准备香港秋招、口语面试和课程作业的个人用户。
- **解决的问题**：今天先做什么、做了多少、离本周目标还差多少。
- **核心循环**：每周自动生成固定任务 + 自己补充待办 → 每日自动挑出少量任务 → 勾选完成 → 即时获得卡拉米 → 在成就查看本周进度。重要面试、DDL等日期单独记在日历。
- **产品原则**：
  1. 每天只聚焦最多3项未完成任务，降低启动压力。
  2. 完成即奖励，正向反馈，不因没做完而扣分。
  3. 节奏可调：可手动安排今日、移到下周、清空后恢复；误点完成当天可撤销。
  4. 页面只放可操作的信息，不放装饰口号、重复统计和大空状态卡。
  5. 数据只存在本机浏览器，无账号、无云端；靠备份迁移。

## 2. 板块总览

应用共 **4个主板块**，底部导航从左到右为 **成就 → 每日 → 待办 → 日历**；打开应用默认进入 **每日**。

| 板块 | 回答的问题 | 主要功能 |
| --- | --- | --- |
| 成就 | 这周进展如何？ | 本周日期、卡拉米余额、三类目标进度、课程周数、奖励明细 |
| 每日 | 今天先做哪几件？ | 当天任务清单（自动/手动安排）、勾选完成、到期提醒、当天统计 |
| 待办 | 我有哪些任务？ | 结构化任务清单、添加/编辑、筛选、跨周与清空、恢复 |
| 日历 | 哪些日子要记住？ | 月历、重要事项标记、添加/查看/编辑/移除提醒 |

**全局元素**：顶部左侧为品牌 You Did!（点击回到每日）；右侧为卡拉米余额（点击进入成就）。各页右上角的专属操作：成就页为设置与数据备份图标，待办页为「添加待办 +」，日历页为「添加提醒 +」，每日页没有。保存出错时任意页面顶部都会显示提示条，可直接打开设置导出备份。设置是辅助入口，不占底部导航。

**使用环境**：手机网页优先，以390px宽为参考、320px可用；电脑浏览器居中显示390px手机视图。支持 iOS「添加到主屏幕」，以独立窗口打开，名称 You Did!，图标为「奖励星星」。正式网址：https://sum-tree.github.io/You-Did/ 。

## 3. 各板块功能

### 3.1 成就

| 功能 | 说明 |
| --- | --- |
| 本周范围 | 显示「本周 · 周一 — 周日」日期 |
| 我的卡拉米 | 一行显示累计余额，与顶部余额一致 |
| 待办项进度 | 香港揾工、大胆说口语各显示名称、百分比、进度条；计算规则见第6节 |
| 课程作业 | 显示第N/15周、学期进度条、剩余周数，「调整周数」进入设置；不显示作业完成数 |
| 卡拉米明细 | 默认折叠，按时间倒序列出每条奖励及日期 |
| 设置与备份入口 | 右上角图标打开设置（3.5）；这是常规入口唯一所在的页面 |

基础目标与特别挑战照常自动结算，只是不在本页展开子项与挑战说明；完整规则在设置中查看。

### 3.2 每日

| 功能 | 说明 |
| --- | --- |
| 日期与安排方式 | 标题为当天本地日期；右侧显示「自动安排」或「手动安排」，点击打开安排面板 |
| 当天统计 | 一行显示今日完成项数与今日获得卡拉米 |
| 到期提醒 | 所有到期/逾期的未完成任务列在提醒区（超过3项时默认展开），每项可直接「改DDL」 |
| 今日清单 | 先列未完成的核心任务（最多3项），再列今天完成的任务（保持勾选）；同一任务只出现一次 |
| 完成与菜单 | 点圆圈完成并即时提示所得卡拉米；「…」打开任务菜单（同3.3） |
| 空状态 | 只显示「今天暂无任务」 |

本页不提供新建任务；新任务在待办添加。安排规则见第5节。

### 3.3 待办

| 功能 | 说明 |
| --- | --- |
| 清单 | 表格式紧凑清单，列为：完成圈、标题、类型、DDL、优先级；点标题展开计划周、目标贡献与数量、DDL说明和「任务操作」 |
| 筛选 | 清单内工具栏：计划周（本周/下周/往周/已清空）、类型（全部/香港揾工/大胆说口语/课程作业）、是否显示已完成；切换页面后筛选保留 |
| 添加待办 | 右上角「+」打开表单：标题（必填）、任务类型、优先级 P0/P1/P2、截止日期（选填）、新建时可勾选「加入今日核心任务」。新任务计划在本周；目标贡献与数量由标题识别（4.2） |
| 任务菜单 | 未完成：编辑任务/修改DDL、加入或移出今日、移至下周、清空（可恢复）。已清空：恢复任务。已完成：查看说明；当天完成的可「撤销完成」（4.4） |
| 批量操作 | 清单底部显示当前筛选中的未完成数量，可「移至下周」（下周视图不显示）或「清空」；确认时显示受影响项数，只处理当前筛选的未完成任务 |
| 空清单 | 保留表头，显示「暂无记录」 |

### 3.4 日历

| 功能 | 说明 |
| --- | --- |
| 月历 | 周一至周日网格，前后月切换、「回到今天」；区分今天、选中日期和非本月日期 |
| 事项标记 | 有事项的日期显示圆点 |
| 添加提醒 | 右上角「+」打开表单：事项名称、日期（默认选中日期）、时间（选填）、类型（面试/测试、重要截止日期、提醒事项）、备注 |
| 当日事项 | 点日期打开底部面板，按时间列出事项的类型、标题、备注，可编辑或移除；无事项时显示简短提示 |

日历事项与任务互相独立：不会自动生成任务、不计入目标、不发卡拉米；修改任务DDL也不会改动日历。提醒只在应用内查看，没有系统推送。

### 3.5 设置

从成就页右上角图标或课程卡「调整周数」打开；出错提示条也可打开。内容：学期周数（1–15周手动选择）；导出备份、导入备份（替换前确认）、数据损坏时导出原始记录、丢弃待保存备份；奖励、进度、每周自动任务和撤销规则说明；版本号。

## 4. 任务、目标与奖励

### 4.1 任务类型与每周目标

| 类型 | 每周基础目标 | 特别挑战 |
| --- | --- | --- |
| 香港揾工 | 投递15份简历，**且**完成本周所有计划中的测试/面试 | 超出15份后每多3份一档 |
| 大胆说口语 | 粤语30分钟 × 2次，**且**英语面试题 × 9题 | 听力每10分钟一档 |
| 课程作业 | 无每周数量目标；学期共13周课程 + 2周考试，初始第6/15周，由用户手动推进 | 无 |

每项任务属于一种类型，并带有一种目标贡献及数量（如「投递3份简历」贡献3份简历）。不计目标量的普通任务也属于某一类型。

### 4.2 目标贡献识别

添加或编辑任务时不需要手选目标，系统按标题和类型识别：

| 类型 | 标题含有 | 计入 | 数量取自 |
| --- | --- | --- | --- |
| 香港揾工 | 面试、测试、笔试、interview | 测试/面试 | 固定1 |
| 香港揾工 | 简历、投递、cv、resume | 简历投递 | 紧挨「份/封/个/家」的数字，或「x5」写法 |
| 大胆说口语 | 听力、listening | 听力 | 「分钟」数，或「小时」×60 |
| 大胆说口语 | 粤语、cantonese | 粤语练习 | 「次」数，或分钟数÷30 |
| 大胆说口语 | 英语、面试题、english | 英语面试题 | 「题/道」数 |
| 课程作业 | — | 课程任务 | 固定1 |

同时命中时按表中从上到下的顺序取第一个；都不命中则为普通任务。没有写数量时记1。只认紧挨单位的数字，「2026校招」之类不会被当成数量。

### 4.3 卡拉米奖励

| 事件 | 卡拉米 |
| --- | ---: |
| 完成任意一项任务（含课程任务，不叠加） | 5 |
| 香港揾工本周基础目标达标 | 20 |
| 超出15份后每多投递3份简历 | 10 |
| 大胆说口语本周基础目标达标 | 20 |
| 听力每10分钟 | 5 |

- 任务奖励按任务计，目标按数量计：一项投递18份简历的任务只有一份任务奖励。
- 基础目标与挑战自动结算，无需领奖；挑战须基础目标达标后才发，达标时自动补发已累计的整档。
- 同一任务、同一周基础目标、同一周挑战档位都只奖励一次。
- 清空、编辑、移至下周、新增面试都不会收回已发奖励。
- 例：本周没有面试安排时，完成一项「投递18份简历」可得 5 + 20 + 10 = 35。若本周还有未完成面试，先只得5；面试完成后再结算20与10。

### 4.4 撤销完成

误点完成时，**当天**可在任务菜单「撤销完成」，隔天后不可撤销。撤销后任务回到未完成，并收回：

1. 该任务的5卡拉米；
2. 当天发放、与该任务同类别、且撤销后不再达标的基础目标或挑战奖励（简历/口语/听力按数量判断，撤销面试时按面试是否仍全部完成判断）。

撤销课程任务或普通任务不影响目标奖励。

## 5. 每日安排规则

### 5.1 自动安排（默认）

每天的核心任务按以下顺序挑选，未完成核心任务最多3项：

1. **一条本周简历自动任务**（本周简历还有未完成的就保证有一条）。
2. **到期/逾期的普通任务**，DDL从早到晚，总数不超过3项。
3. 不足2项时，用本周普通任务按优先级 P0 → P1 → P2、再按DDL补到2项。
4. 仍不足3项时，加**一条口语自动任务**：英语优先；本周英语全部完成后才安排粤语。

- 同一自动任务系列每天最多一条：当天完成一条后不再补同系列下一条；英语和粤语不会同一天出现。
- 未完成项减少时，普通任务会自动补位。
- 下周计划的任务不参与补位，但一旦到期或逾期就进入提醒与候选。往周未完成任务可手动加入今日。
- 放不下的到期任务仍完整显示在提醒区。

### 5.2 手动安排

在安排面板中从可安排任务（本周及以前计划的未完成任务、已到期任务）勾选最多3项后保存，当天严格按所选显示，不套用5.1规则、不自动补位；允许保存空选择。点「恢复自动安排」回到5.1。任务菜单的「加入今日/从今日移出」也会把当天转为手动安排。

### 5.3 每周自动任务

每周第一次打开应用时，待办自动生成本周固定任务：

| 任务 | 条数 | 每条计入 |
| --- | ---: | --- |
| 香港秋招简历x5 | 3 | 简历5份 |
| 英语面试练习3题 | 3 | 英语面试题3题 |
| 粤语30分钟 | 2 | 粤语练习1次 |

全部完成正好满足香港揾工的简历目标和大胆说口语的两项目标。

- **每周日晚0点清空**：新的一周开始时，上周未完成的自动任务移入「已清空」（可恢复，恢复后不会再被清空）；已完成记录与奖励保留。
- 本周自动任务被清空或修改后不会重新生成。
- 应用不在后台运行，生成和清空在下次打开时按当前日期补做；多页同时打开不会重复生成。

## 6. 进度、跨周与日期

1. **双条件进度**：两个子目标各算完成比例（上限100%）再取平均；两项都达标才显示100%。本周没有面试安排时面试条件视为满足，所以只差简历时显示50%。
2. **新增面试**会重新计算进度，进度可以下降；已发奖励不收回，同周基础目标也不会再次发放。
3. **按实际完成周计**：贡献与奖励计入完成当天所在的周。上周计划、本周完成的面试计入本周面试要求；提前在更早的周完成的面试，同时满足原计划周的要求。
4. **移至下周**：计划周改为下周一；早于下周一的DDL调整为下周一，更晚的DDL和空DDL保持不变。已在下周或更晚的任务不受影响。若因移走面试使本周目标达标，立即结算。
5. **清空**是可恢复的归档。清空的未完成面试仍算原计划周的要求。普通未完成任务不会跨周自动删除，往周记录始终可见；每周自动任务按5.3清空。
6. **挑战累计**：整周累计，未满一档不发分，剩余量不跨周。
7. **日期**：以浏览器本地日历计，每周从周一开始；写入使用点击时的本地日期，跨午夜或页面重新可见时立即更新日期。

## 7. 数据保存、备份与多页保护

- **本地保存**：单用户，数据保存在当前设备、浏览器和网址下；刷新后恢复任务、完成记录、奖励流水、日历、每日安排、课程周数。初始任务与余额为空，课程为第6/15周。
- **不自动同步**：换设备、换网址或清理浏览器前须先导出备份。
- **备份**：导出为完整JSON。导入会替换全部记录：先校验格式及任务、完成记录、每日安排、奖励之间的一致性，拒绝重复奖励、不一致的完成记录和孤立奖励，只保留已知字段，并在替换前确认。
- **损坏保护**：本地记录损坏或不兼容时不会被初始化或自动生成覆盖，可导出原始记录，再导入有效备份恢复。
- **多页冲突保护**：所有写入（含导入和每周自动生成）都经同一安全写入流程。编辑窗口以打开时的记录为准，若期间另一页已改动，本次保存被拒绝并提示，输入保留，可导出包含本次改动的「待保存备份」；不自动合并。页面同步只读取，不回写。
- **保存失败**：空间不足、读取失败或浏览器缺少安全写入能力时显示错误，不假报成功，不降级到可能互相覆盖的写法。
- 发布新版本后，已打开的旧页面须刷新后再编辑。

## 9. 当前状态与范围
