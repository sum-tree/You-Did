## 1. 应用核心

**You Did! 是为史同学定制的求职期效率应用：在最后一年求职的高压环境下，尽量减少焦虑和压力，帮她在漫长的求职拉锯战中保持好心态，平衡求职与学业，并提高英语和粤语口语。**

- **服务对象**：史同学（个性化版本）。
- **核心问题**：减少焦虑；明确每天做什么；开心地完成任务。
- **核心循环**：每周自动生成固定任务 + 自己补充待办 → 每日自动挑出少量任务 → 勾选完成 → 即时获得卡拉米、看到罐子变满 → 在成就查看本周进度。面试、DDL等重要日期单独记在日历。
- **典型场景**：
  1. 每日确认：打开应用，马上知道今天最值得做的几件事。
  2. 临时任务：出现面试或DDL变化，在每日页快速添加任务并调整今日安排。
  3. 可视化努力：完成任务后看到进度更新，以及玻璃罐里的果冻卡拉米增加。
- **产品原则**：
  1. 每天只聚焦最多3项未完成任务，降低启动压力。
  2. 完成即奖励，不因没做完、逾期而扣分或制造惩罚感；不做制造紧迫感的倒计时。
  3. 节奏可调：可手动安排今日、移到下周、清空后恢复；误点完成当天可撤销。
  4. 页面只放可操作的信息，不放装饰口号、重复统计和大空状态卡。
  5. 数据只存在本机浏览器，无账号、无云端；靠备份迁移。

## 2. 产品结构

顶部切换两个板块：**任务** 与 **卡拉米**。打开应用默认进入「任务 · 每日」。（已上线）

| 板块 | 页面 | 回答的问题 | 主要内容 |
| --- | --- | --- | --- |
| 任务 | 成就 | 这周已经走了多远？ | 本周日期、卡拉米余额与明细、香港揾工与大胆说口语百分比、课程周数 |
| 任务 | 每日 | 今天先做哪几件事？ | 今日清单、快速添加任务、「待办」入口 |
| 任务 | 日历 | 哪些日期要记住？ | 面试、测试、重要截止日期及提醒 |
| 卡拉米 | 卡拉米 | 我的努力积累成了什么？ | 玻璃罐中的果冻卡拉米、准确余额、获得记录；以后可能加扭蛋机 |

- 「任务」板块底部导航为 **成就 → 每日 → 日历**。
- **待办不再是顶层页面**：从每日页的「待办」按钮进入，可随时返回每日；清单功能不变（3.3）。
- 成就页保留余额与明细；卡拉米页是**新增**的视图，不是从成就页移走。
- 顶部右侧的卡拉米余额点击后切到卡拉米板块；品牌点击回到每日。右上角按页面显示：成就为设置与备份，每日为「添加任务 +」，待办为「添加待办 +」，日历为「添加提醒 +」，卡拉米板块无。
- 设置与数据备份入口保持在成就页右上角。保存出错时任意页面顶部显示提示条，可直接打开设置。
- **使用环境**：手机网页优先，390px为参考、320px可用；电脑浏览器居中显示390px手机视图。支持 iOS「添加到主屏幕」，名称 You Did!，图标「奖励星星」。正式网址：https://sum-tree.github.io/You-Did/ 。

| 功能 | 说明 |

## 4. 任务、目标与奖励

### 4.1 任务类型与每周目标

| 类型 | 每周基础目标 | 额外挑战 |
| --- | --- | --- |
| 香港揾工 | 投递至少15份简历，**且**完成本周所有计划中的测试/笔试与面试 | 超过15份后每满3份一档 |
| 大胆说口语 | 粤语30分钟 × 2次，**且**英语面试题 × 9题 | 粤语或英语听力每满10分钟一档 |
| 课程作业 | 无每周数量目标；学期13周课程 + 2周考试，初始第6/15周，手动推进 | 无 |

### 4.2 目标贡献识别（已上线）

| 类型 | 标题含有 | 计入 | 数量取自 |
| --- | --- | --- | --- |
| 香港揾工 | 面试、interview | 面试 | 固定1 |
| 香港揾工 | 测试、笔试、test | 测试/笔试 | 固定1 |
| 香港揾工 | 简历、投递、cv、resume | 简历投递 | 紧挨「份/封/个/家」的数字，或「x5」写法 |
| 大胆说口语 | 听力、listening | 听力 | 「分钟」数，或「小时」×60 |
| 大胆说口语 | 粤语、cantonese | 粤语练习 | 「次」数，或分钟数÷30 |
| 大胆说口语 | 英语、面试题、english | 英语面试题 | 「题/道」数 |
| 课程作业 | — | 课程任务 | 固定1 |

同时命中时按表中从上到下取第一个；都不命中为普通任务；没写数量记1；只认紧挨单位的数字。

### 4.3 卡拉米奖励（已上线）

原则：越重要、越难提起积极性的任务，卡拉米越高。

| 任务或事件 | 获得条件 | 卡拉米 |
| --- | --- | ---: |
| 普通任务 | 完成一项不计入专项目标的任务 | 2 |
| 简历投递 | 完成一项；份数计入香港揾工周目标 | 4 |
| 测试 / 笔试 | 完成一项；计入香港揾工周目标 | 8 |
| 面试 | 添加后 0–3 天内完成 | 12 |
| 面试 | 添加后第 4–6 天完成 | 4 |
| 面试 | 添加后第 7–10 天完成 | 2 |
| 面试 | 添加后超过 10 天完成 | 1 |
| 粤语练习 | 完成一项；次数计入大胆说口语周目标 | 2 |
| 英语面试题 | 完成一项；题数计入大胆说口语周目标 | 4 |
| 听力 | 完成一项；分钟数计入听力挑战 | 2 |
| 课程作业 | 完成一项，不叠加普通任务奖励 | 1 |
| 香港揾工周基础目标 | 见4.1 | 10 |
| 香港揾工额外挑战 | 基础目标达成后，超过15份每满3份 | 每档 4 |
| 大胆说口语周基础目标 | 见4.1 | 7 |
| 听力额外挑战 | 基础目标达成后，听力每满10分钟 | 每档 2 |

- 面试天数从**添加任务的本地日期**算起（添加当天为第0天），与DDL无关，修改DDL不重新计时。
- 面试卡片显示「完成可得X · N天后变为Y」，不做倒计时。（已上线）
- 任务奖励按任务计，目标按数量计；基础目标与挑战自动结算，挑战在基础目标达成时补发已累计的整档。
- 同一任务、同一周基础目标、同一周挑战档位只奖励一次；清空、编辑、移至下周、新增面试都不会收回已发奖励。
- **历史奖励按新规则重算**：升级后首次打开时，所有已发奖励按本表重新计算（面试按当时添加与完成日期分档；原「测试/面试」任务中标题含测试或笔试的改为测试/笔试）。余额会随之变化。

### 4.4 撤销完成（已上线）

当天完成的任务可在任务菜单「撤销完成」，隔天后不可撤销。撤销后任务回到未完成，并收回该任务的奖励，以及当天发放、同类别、撤销后不再达标的基础目标或挑战奖励（数量类按数量判断；撤销测试/笔试或面试时按是否仍全部完成判断）。撤销课程或普通任务不影响目标奖励。

### 4.5 面试拆分建议（已实现）

面试任务有DDL且**逾期满3天仍未完成**时，在任务详情或每日任务中建议把准备工作拆成小步；无DDL不触发。是否采用由用户决定，未确认时不改动原任务、DDL和已获奖励。拆出的步骤**不计卡拉米**。

建议步骤：搜集问题 → 写出所有问题的回答 → 每个回答读3遍 → 记住2道回答 → 记住5道回答 → 记住所有回答 → 录一次视频 → 回看视频找问题 → 再录一次 → 再次回看 → 录最终视频。

先请用户填写或确认问题总数，再按总数调整：不足2道或5道时不生成超出总数的步骤；「记住所有回答」对应实际总数，与前面步骤重复时去掉重复项。用户可删改步骤。完成全部步骤后，完成原面试任务并按4.3获得对应档位奖励。

## 5. 每日安排与每周任务（已上线）

### 5.1 自动安排

未完成核心任务最多3项，按顺序挑选：

1. 一条本周简历自动任务（本周还有未完成就保证有一条）。
2. 到期/逾期的普通任务，DDL从早到晚，总数不超过3。
3. 不足2项时，用本周普通任务按 P0 → P1 → P2、再按DDL补到2项。
4. 仍不足3项时，加一条口语自动任务：英语优先，本周英语全部完成后才安排粤语。

同一自动任务系列每天最多一条；英语和粤语不同天出现；未完成项减少时普通任务自动补位；下周计划的任务到期后进入候选；放不下的到期任务在待办中可见。

### 5.2 手动安排

在安排面板勾选最多3项后保存，当天严格按所选显示，不套用5.1、不补位，可保存空选择；「恢复自动安排」回到5.1。任务菜单「加入今日/从今日移出」也会转为手动安排。

### 5.3 每周自动任务与每周清空

每周第一次打开时，待办自动生成：香港秋招简历x5（3条，每条计5份）、英语面试练习3题（3条，每条计3题）、粤语30分钟（2条，每条计1次）。

**每周清空**（PRD-New「每周清空前一周任务，不清空卡拉米」的具体范围）：新的一周开始时，上周未完成的**这些自动任务**（简历x5、英语3题、粤语30分钟）移入「已清空」，可恢复；面试、测试、课程作业和用户自己添加的任务不清空；卡拉米和已完成记录不受影响。应用不在后台运行，生成与清空在下次打开时补做。

## 6. 进度、跨周与日期

1. **双条件进度**：两个子目标各算完成比例再平均，都达标才显示100%。香港揾工本周没有测试/面试安排时只按简历计算。
2. 新增测试或面试会重算进度，进度可下降；已发奖励不收回。
3. 贡献与奖励计入实际完成周；上周计划、本周完成的测试/面试计入本周要求；提前完成的同时满足原计划周。
4. 移至下周：计划周改为下周一，早于下周一的DDL调整为下周一；已在下周或更晚的不受影响；因移走测试/面试使本周达标时立即结算。
5. 清空是可恢复的归档；清空的未完成测试/面试仍算原计划周的要求。
6. 挑战整周累计，未满一档不发分，剩余量不跨周。
7. 日期按浏览器本地日历，每周从周一开始；跨午夜或页面重新可见时立即更新。

## 7. 数据保存、备份与多页保护

- 单用户本地保存：任务、完成记录、奖励流水、日历、每日安排、课程周数；初始余额为0，课程第6/15周。
- 不自动同步；换设备、换网址或清理浏览器前先导出备份。
- **数据版本**：当前为第2版（新奖励规则）。第1版记录（本地或备份）先按旧规则校验，再升级并重算奖励（4.3）；升级在内存中进行，下一次保存时写回。打开着的旧版本页面会读不懂新记录并停止写入，刷新即可。
- 备份导入替换全部记录：校验格式与一致性，拒绝重复奖励、不一致的完成记录、孤立奖励和与规则不符的奖励数值，只保留已知字段，替换前确认。
- 损坏或不兼容的记录不会被覆盖，可导出原始记录再导入有效备份。
- 多页冲突保护：所有写入（含导入和每周自动生成）经同一安全写入流程；编辑窗口以打开时的记录为准，期间他页改动则拒绝保存、保留输入、可导出待保存备份。保存失败时显示错误，不假报成功。
